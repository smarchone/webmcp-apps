      Installation

      Run these in a terminal to let Claude Code analyse data and plot it on this map.

      1. Add the WebMCP bridge to Claude Code
      claude mcp add webmcp -- npx -y @smarchone/webmcp-bridge
      2. Ask Claude to map something
      claude "Open https://smarchone.github.io/webmcp-apps/maps/ with the webmcp tools and plot the IITs in India"

      Run both in the same folder; Claude saves its data files there. Requires Node 22+ and Chrome.
