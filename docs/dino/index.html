Let Claude Code play

Needs Claude Code, Node 22+ and Chrome. Run these in a terminal. Claude opens its own Chrome window and plays the game there.

  1. Add the WebMCP bridge (once)
    claude mcp add -s user webmcp -- npx -y @smarchone/webmcp-bridge
  2. Play
    claude "Open https://smarchone.github.io/webmcp-apps/dino/ with the webmcp tools and play one game"
